# NEXUS
NEXUS is a TypeScript-based ecommerce frontend.

# Commands

```bash
npm install
npm run build
npm run typecheck
```

# Phase 1

- TypeScript project configuration
- Strict TypeScript setup
- Product and cart models
- Fake Store API service
- LocalStorage state for cart and favorites
- Shared NEXUS store
- Shared DOM utilities
- Main application entry point
- HTML pages connected to the compiled TypeScript

The visual styling is intentionally reserved for Phase 2.
