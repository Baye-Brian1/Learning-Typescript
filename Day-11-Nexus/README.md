# NEXUS
NEXUS is a TypeScript-based ecommerce frontend.

# Commands

```bash
npm install
npm run build
npm run typecheck
```

# Phase 1

- TypeScript project configuration
- Strict TypeScript setup
- Product and cart models
- Fake Store API service
- LocalStorage state for cart and favorites
- Shared NEXUS store
- Shared DOM utilities
- Main application entry point
- HTML pages connected to the compiled TypeScript

The visual styling is intentionally reserved for Phase 2.

# Phase 2

- Where something is
- How big it is
- What color it is
- Spacing
- Borders
- Animations
- Responsive layout
- Hover states
- Visual appearance

# Phase 3

- Fetching products
- Searching
- Filtering
- Sorting
- Adding to cart
- Removing from cart
- Changing quantity
- Favorites
- Pagination
- Updating badges
- Rendering products
- LocalStorage
- API communication
