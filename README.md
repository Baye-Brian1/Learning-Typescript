# TypeScript Learning Journey
Welcome to my **TypeScript Learning Repository**.
This repository documents my journey learning TypeScript from the fundamentals to more advanced concepts. I organized my learning into **10 days**, with each day focusing on a specific TypeScript concept and practical exercises.
The goal of this repository is not only to learn TypeScript syntax, but also to understand how TypeScript improves JavaScript development through **static typing, better code structure, type safety, and maintainability**.

## About This Repository
This repository contains my daily TypeScript practice from **Day 1 to Day 10**.
Each day contains practical exercises and/or a small project designed to reinforce the concepts learned that day.

### Learning Progression

Day 1  → Variables & Types
Day 2  → Arrays, Objects & Tuples
Day 3  → Functions
Day 4  → Interfaces & Type Aliases
Day 5  → Classes & Object-Oriented Programming
Day 6  → Generics
Day 7  → Enums, Unions & Literal Types
Day 8  → Promises & Async/Await
Day 9  → Modules & Imports/Exports
Day 10 → Converting JavaScript to TypeScript

### Topics Covered

* TypeScript variables
* Primitive types
* Type annotations
* Type inference
* `string`
* `number`
* `boolean`
* Understanding how TypeScript detects incorrect values
